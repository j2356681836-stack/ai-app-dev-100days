# Preferred AI Collaboration Style

请使用：

- 通俗解释，少一点架构黑话
- 先讲直觉，再讲原理
- 用企业真实案例类比
- 更像高级工程师带新人
- 保留工程严谨性
- 强调 WHY
- 强调工程 tradeoff
- 不只给答案，要分析根因

在每一天学习结束进行收尾的时候要求： 
- 中文更新git
- git按照"feat(day29):……"包含进度时间和当日学习内容总结的格式
- 中文更新Readme.md 
- 中文project_state.md 
- 中文更新daily_log.md 
- 保持前后格式和架构一致 
- 按照实际进度对PROJECT_STATE的未来规划进行更新 
- 避免出现实际进度超过过去的规划导致学习时长不规律
